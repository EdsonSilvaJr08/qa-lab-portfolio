01 — Demonstração

Uma jornada gravada com Playwright

O script de demonstração executa o login com dados fictícios, cria um chamado, confere seu resultado, pesquisa o registro e altera seu status. A gravação foi produzida pelo navegador durante a execução do script; não é uma animação.

O vídeo documenta um fluxo específico. Ele não substitui os dez cenários da suíte oficial nem é uma execução ao vivo.

04 — Escopo e decisões

Como interpretar este estudo

Fluxos escolhidos
Cadastro, autenticação e chamados concentram os comportamentos de validação, estado e persistência exercitados neste laboratório.
Execuções independentes
Os cenários E2E utilizam contextos de navegador isolados para evitar que os dados de um teste interfiram nos seguintes.
O que não foi validado
Os casos manuais estão escritos, mas ainda não há registro de execução manual. Não foram realizados testes de carga, auditoria abrangente de acessibilidade nem avaliação de segurança para produção.
Limitação do sistema
O PulseDesk não possui backend ou banco de dados compartilhado. As contas e os chamados são fictícios e ficam no armazenamento local de cada navegador; não utilize dados ou senhas reais.
