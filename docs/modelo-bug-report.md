# Modelo de bug report — sem defeito inventado

Preencha somente após reproduzir um defeito real, com evidências reais.

- **ID:** BUG-XXX
- **Título:** [funcionalidade] comportamento observado
- **Ambiente:** commit, navegador/versão, SO e URL
- **Pré-condições:** conta de teste e estado inicial
- **Passos para reprodução:** numerados
- **Resultado esperado:** conforme RF-XX
- **Resultado observado:** comportamento reproduzido
- **Frequência:** ocorrências/tentativas medidas
- **Severidade:** justificar impacto do defeito
- **Prioridade:** proposta, sujeita a validação
- **Evidências:** screenshot, vídeo, trace, logs sem dados sensíveis
- **Status:** aberto / em análise / corrigido / reteste

Não criar print, frequência ou defeito hipotético como se fosse uma descoberta.
